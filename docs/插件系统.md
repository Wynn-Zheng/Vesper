# 插件系统

控制台 → **插件** 页：上面是 11 个内置能力，下面是外部插件面板（安装 / 卸载 / 启停 / 重载 / 检查更新）。

## 目录结构

```
plugins/
└── my-plugin/
    ├── plugin.json     ← 清单（必须有）
    └── index.js        ← 入口（manifest 的 entry 指向它）
```

`plugins/*` 已 gitignore（只有 `plugins/demo/` 例外，作为示例）。

## 清单 `plugin.json`

```json
{
  "id": "my-plugin",
  "name": "我的插件",
  "version": "0.1.0",
  "description": "一句话说它干什么",
  "author": "你",
  "entry": "index.js",
  "minHostVersion": "0.1.0"
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 只能小写字母、数字、连字符（`^[a-z0-9-]+$`），也是目录名 |
| `name` | ✅ | 显示名 |
| `version` | ✅ | 三段数字 `1.2.3`，可带 `-beta.1` 后缀 |
| `entry` | ✅ | 入口文件，**必须真实存在**（安装时会校验） |
| `description` | | 一句话简介，显示在面板里 |
| `author` | | 作者 |
| `minHostVersion` | | 要求的最低宿主版本；当前不满足会**直接拒绝安装** |

## 入口 `index.js`

项目是 ESM（`package.json` 里有 `"type": "module"`），所以用 `export`：

```js
export function activate(ctx) {
  ctx.log('插件启动了')
  // ctx.config 是这个插件在 persona/plugins.yaml 里的配置
  const { 间隔秒数 = 60 } = ctx.config
  ctx.log(`间隔 ${间隔秒数} 秒`)
}

export function deactivate(ctx) {
  ctx.log('插件停了，清理定时器之类的')
}
```

**导出的三种写法都认**：
- `export function activate(ctx)`
- `export default function (ctx) {}`
- `export default { activate, deactivate }`

**必须导出激活函数**，否则加载失败（`插件没有导出激活函数`）。

## `ctx` 提供什么

| 成员 | 说明 |
|---|---|
| `ctx.id` | 插件 id |
| `ctx.dataDir` | 这个插件专属的数据目录（`data/plugins/<id>/`，激活前已建好） |
| `ctx.config` | `persona/plugins.yaml` 里这个插件的 `config`，**激活时读一次快照** |
| `ctx.log(msg)` | 写业务日志（进 `data/logs/*.jsonl`，控制台「运行日志」能看到） |
| `ctx.on(event, fn)` | 订阅插件内部事件 |
| `ctx.emit(event, payload)` | 发一个插件内部事件（只在本插件内广播） |

**注意**：
- 改配置要**重载插件**才生效（`config` 是快照）
- 插件异常会被宿主吞掉并记进 `errors`，**不会把别的插件带崩**
- 外部插件是**任意 JS**，能读写你的文件和密钥。**装之前确认来源可信**

## 配置 `persona/plugins.yaml`

```yaml
plugins:
  demo:
    config:
      说明: demo 的配置会原样传进 ctx.config
      示例数字: 42
```

**启用/禁用不在这里** —— 那是 `plugins/<id>/disabled` 标记文件（跟插件目录同生共死，卸载时自动没了）。

## 接口（后端）

| 方法 + 路径 | 作用 |
|---|---|
| `GET /api/plugins/list` | 列表（含 `config`、`enabled`、`loaded`） |
| `POST /api/plugins/install` | `{ source: "本地目录绝对路径" }`。**只支持目录，不支持 .zip**；失败会回滚 |
| `POST /api/plugins/uninstall` | `{ id, purgeData?: true }`，顺带清掉它的配置 |
| `POST /api/plugins/toggle` | `{ id, enabled }` |
| `POST /api/plugins/reload` | `{ id }`，卸载再加载（拿到新的 `ctx.config`） |
| `POST /api/plugins/config` | `{ id, config }`，写 `persona/plugins.yaml`，**重载后生效** |
| `GET /api/plugins/updates` | 对比 `plugins/index.json` 里的版本 |

## 检查更新

放一份 `plugins/index.json`：

```json
{
  "plugins": [
    { "id": "my-plugin", "version": "0.2.0" }
  ]
}
```

面板点「检查更新」会对比本地 `plugin.json` 和这份清单，版本低的标出来。**没有这个文件也不影响插件运行**，只是检查不了更新。

## 安全边界

- **安装时校验**：清单格式、id 合法性、入口文件存在、`minHostVersion`
- **安装时拒绝**：`.zip`（要求先解压）、清单非法、同 id 已存在（除非显式覆盖）
- **卸载时**：id 走 `isSafeId` 校验，挡住 `../../src` 这类路径穿越
- **不做**：沙箱、进程隔离、权限声明。**插件跟主进程同权限**
