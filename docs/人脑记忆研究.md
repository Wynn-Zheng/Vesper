## 二、记忆不是一块砖，是几个系统

### Squire (2004)：两大类

```
记忆
├── 陈述性（能说出来）
│   ├── 情景（episodic）：具体某件事、有时间地点
│   └── 语义（semantic）：事实、概念，没有"当时"
└── 非陈述性（说不出来）
    ├── 程序性（骑车、打字）
    ├── 启动效应
    ├── 经典条件反射
    └── 非联合学习
```

**对标的**：我们的 `episode` = 情景，`facts` = 语义。

**关键差异**：**脑损伤病人可以情景记忆全失、但语义记忆保留**（Squire 的经典病例）。说明**这是两套独立的系统，不是同一套的深浅**。

**这条支持你的分档想法**：**不同类型的记忆本来就走不同的通路**。

### Tulving (1985)：情景记忆需要"自我"

Tulving 提出情景记忆的核心是 **autonoetic consciousness**（自我觉知）——"我记得**我**当时在场"。

语义记忆只要 **noetic**（知道），不需要"我在场"。

**对标的**：我们的 `episode` 存了 `date` / `emotion` / `title`，正是因为需要"当时"的锚点。**这个设计是对的**。

## 三、短时 → 长时：两个系统，一条通路

### Atkinson & Shiffrin (1968)：多存储模型

```
感觉记忆（几百毫秒）
    ↓ 注意
短时记忆（约 15-30 秒，容量 7±2）
    ↓ 复述
长时记忆（近乎无限）
```

**关键机制是「复述」**——**不复习就掉出去**。

**对标的**：
- `session`（40 轮）≈ 短时
- `raw` 7 天 ≈ 缓冲
- `distill` 后的 `episode/fact` ≈ 长时

### Baddeley & Hitch (1974)：工作记忆不是"短时"

他们发现短时记忆不是单一储物箱，是**几个并行的工作区**（语音环路 / 视空间模板 / 中央执行）。

**对我们的意义**：**"当前会话"不是一个队列，是几条并行的线**（对话 / 关系 / 情绪）。我们的 `session + relation + mood` 分开存，方向对。

## 四、⭐⭐ 最重要的一条：遗忘是幂函数，不是指数

### Wixted & Ebbesen (1991)

这篇直接改变了我们的实现。

**原文摘要**（从 [APS 官网](https://www.psychologicalscience.org/journals/psychological-science/j.1467-9280.1991.tb00175.x/) 抓的）：

> Three experiments are reported, two involving human subjects and one involving pigeons. The human experiments investigated this issue using recall of words and recognition of faces, whereas the pigeon experiment employed the standard delayed matching-to-sample task. **In all cases, the course of forgetting was best described by a simple power function of time relative to five other reasonable alternatives (linear, exponential, exponential-power, hyperbolic, and logarithmic).** Furthermore, a reanalysis of Ebbinghaus's (1885) classic savings function showed that it, too, **declines as a power function of time**.

**他们比了 6 种函数，幂函数赢了**：

| 函数 | 形式 | 结果 |
|---|---|---|
| 线性 | `a - bt` | ❌ |
| **指数** | `a·e^(-bt)` | ❌ **就是这个我们用的** |
| 指数-幂 | `a·e^(-b·t^c)` | ❌ |
| 双曲 | `a/(1+bt)` | ❌ |
| 对数 | `a - b·ln(t)` | ❌ |
| **幂** | **`a·t^(-b)`** | ✅ |

**Murre & Dros (2015) 复现了 Ebbinghaus**，也支持幂函数。

### 差别有多大

```
指数 e^(-0.02t)    t=30 天 → 0.55    t=90 天 → 0.17    t=365 天 → 0.00
幂律 t^(-0.5)      t=30 天 → 0.18    t=90 天 → 0.11    t=365 天 → 0.05
```

**指数衰减后期掉得比幂律快得多**——指数函数在长期趋近 0，幂函数有**长尾**。

**这就是为什么"三年前的事虽然模糊，但还记得有那么回事"**。

**我们的问题**：`exp(-0.023 * days)` 半年后基本归零，但真实记忆不是这样。

### 建议改法

```ts
// 现在（指数）
const recency = Math.exp(-lambda * days)

// 改成（幂律 + 平滑）
// 加 1 是为了 t=0 时不炸
const recency = Math.pow(1 + days, -lambda * 10)
```

**但要注意**：幂律在 `t=0` 时是无穷大，所以要加平滑项。

## 五、⭐⭐ 第二重要：遗忘不是删除，是取不出来

### Bjork & Bjork 的「新失用理论」（New Theory of Disuse）

> 注：这是书章，没有独立 DOI，所以我没列进上表。它被反复引用和验证，但严格说不是"期刊论文"。
> 我把它单独标出来，是因为它对我们影响最大，同时提醒读者：**这一条的可查证性弱于上面 12 篇**。

核心区分：

| | 存储强度（storage strength） | 提取强度（retrieval strength） |
|---|---|---|
| 是什么 | 记忆本身有多牢 | 现在能不能想起来 |
| 会下降吗 | **不会，只增不减** | **会，随时间掉** |
| 怎么提高 | **成功回忆一次就提高** | 刚回忆过时最高 |

**关键结论**：

1. **遗忘是提取失败，不是痕迹消失**
2. **"想不起来"不代表"没记住"**
3. **每次成功回忆，存储强度都会上升**（哪怕当时提取强度很低）

**这解释了一个反直觉现象**：**适度遗忘反而有利于长期记忆**（因为需要费力提取，而费力提取会加强存储）。

### Roediger & Karpicke (2006)：测试效应

这篇是上面理论的实验证据（2308 次被引）。

**做法**：两组学同一段材料
- A 组：反复**阅读** 4 遍
- B 组：读 1 遍 + **测试** 3 遍

**结果**：
- **5 分钟后**：A 组记得更多
- **1 周后**：**B 组记得明显更多**

**"测试"（主动回忆）比"重读"对长期记忆有效得多**。

**对标的**：我们的 `Episode.lastRecalled` 现在**只用来算排序**，没有用来加强记忆。

**应该改成**：每次被召回，**存储强度 +1** —— 越常想起的，越难忘。

### Nader, Schafe & LeDoux (2000)：再巩固

**原文标题**：*Fear memories require protein synthesis in the amygdala for reconsolidation after retrieval*

**发现**：记忆被**回忆**时会进入一个不稳定的窗口期，需要重新合成蛋白质才能稳定下来。**在这个窗口期里，记忆可以被修改**。

**含义**：**回忆不是读取，是重写**。

**对我们的启发**：
- 每次召回都**重新写一遍**（更新 `lastConfirmed`），是符合生物学的
- 但也意味着**记忆会漂移**——反复回忆的内容会越来越"像我们想的那样"，不是"本来那样"

## 六、情绪决定忘不忘得掉

### McGaugh (2004)

**原文标题**：*The amygdala modulates the consolidation of memories of emotionally arousing experiences*

**发现**：杏仁核在**情绪唤起**时释放应激激素（肾上腺素、皮质醇），**加强海马对这段经历的巩固**。

**效果**：**情绪强烈的事件记得更牢**，而且这个效应是**剂量相关**的（越激动越牢）。

**对标的**：我们 `lambdaOf()` 里"高情绪 → 0.005（139 天半衰期）"**方向是对的**，但：
- 现在是靠 `importance >= 8` 判断
- **应该用 `emotion` 有没有值 + 强度**判断，不是 importance 分数

## 七、记忆不合并，是叠加

### Hintzman (1986)：多痕迹模型

**核心**：每经历一次，就存**一条独立的痕迹**。不合并成"抽象图式"。

只有在**需要抽象**时，才从多条痕迹里**临时**算出来。

**这解释了"图式"从哪来**：不是存在某个地方，是**每次从多条实例里现算**。

**对我们的冲突**：

我们现在**拼命去重**：
- `facts.md`：`sim > 0.9` 判重
- `life.md`：`similarity > 0.5` 就丢
- `plays.md`：`sim > 0.7` 就丢

**但多痕迹模型说：不要合并，要保留多条**。

**折中方案**：
- **事实**（fact）可以合并（"他喜欢猫"说两次还是一条）
- **情节**（episode）**不该合并**（"周一他吐槽老板"和"周五他吐槽老板"是两件事）
- **表达**（plays）可以合并（同一句话学一次就够）

**我们现在 episode 是保留的**（按天分文件），**这个是对的**。但 `life.md` 和 `plays.md` 的去重可能过度了。

## 八、快学 + 慢学：两个系统配合

### McClelland, McNaughton & O'Reilly (1995)

**问题**：为什么大脑需要**海马**和**皮层**两套系统？

**答案**：**它们解决的是同一个矛盾的两面**：

| | 海马 | 皮层 |
|---|---|---|
| 学得快吗 | **快**（一次就记住） | 慢（要反复） |
| 会覆盖旧知识吗 | 不会（独立存） | **会**（新知识冲掉旧的） |
| 适合 | 具体事件、例外 | 统计规律、一般知识 |

**如果只有皮层**：新事学得慢，而且会**灾难性遗忘**（学新的忘旧的）。

**如果只有海马**：学得快但**没法泛化**。

**两套配合**：海马先快速记下具体事件，**在睡眠中反复"重播"给皮层**，皮层慢慢抽出统计规律。

### Kumaran, Hassabis & McClelland (2016)：20 年后的更新

**这是专门写给 AI 研究者的**（标题就叫 *What Learning Systems do Intelligent Agents Need?*）。

**关键补充**：
- **重播（replay）不需要真的睡觉**——可以是任何"离线"时段
- **重播是有选择的**：优先重播**意外的**、**有奖励的**、**还没学会的**
- **不只是两套，可能是多套**（他们提议加一个"前额叶"式的、负责规则的）

**对标的**：
- 我们的 `raw`（海马）→ `distill`（重播）→ `episode/fact`（皮层）**结构是对的**
- **缺的是**：distill 现在是**定时全量**，不是**有选择地挑意外的/重要的**

## 十、具体要改什么（已完成，留作实现说明）

> 这一节写的是"怎么改"的方案。**2026-11 已经全部实现了**，留着是为了说明
> 为什么这么写代码 —— 不是待办清单。

### 1. 衰减函数：指数 → 幂律 ✅ 已改

```ts
// src/memory/recall.ts scoreOf()
// 现在（就是当初建议的那行）
const recency = Math.pow(1 + days, -lambda * 8)
```

**为什么乘 8**：让 `lambda=0.02` 时半衰期仍在 30 天附近，保持参数手感。

### 2. 召回要加强记忆，不只是排序 ✅ 已做

```ts
const slowdown = 1 / (1 + Math.log(1 + recallCount))
return Math.pow(1 + Math.max(0, days), -lambda * 8 * slowdown)
```

**这就是"测试效应"**：越被想起的，越难忘。

### 3. 情绪判断改用 emotion 字段 ✅ 已改

`lambdaOfEpisode()` 现在先看 `emotion` 有没有值、`importance` 够不够，
不再只按 `importance >= 8` 判。

### 4. 去重策略分类型 ⚠️ 部分

| 类型 | 现在 | 结论 |
|---|---|---|
| `facts` | sim > 0.9 判重 | ✅ 保持（事实该合并） |
| `episodes` | 不合并（按天分文件） | ✅ 保持 |
| `life` | 仍较严 | ⚠️ 还没放宽 |
| `plays` | sim > 0.7 就丢 | ✅ 保持 |

### 5. distill 改成选择性重播 ✅ 已做

`memory/filter.ts` 负责挑：`importance >= 7`、带 `emotion`、
和已有记忆不相似（意外）的优先。
