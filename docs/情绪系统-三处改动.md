# 情绪系统：三处改动

> 2026-10-26
> 上一轮查了 18 篇文献（Crossref 验证）+ 3 个 AI 侧参考项目。
> 这份是**落地方案**：每处改动的精确位置、能参考什么、风险、优先级。

---

## 零、先看参考项目

| 项目 | arXiv | 核心做法 | 对我们有没有用 |
|---|---|---|---|
| **Sentipolis** | [2601.18027](https://arxiv.org/abs/2601.18027)（2026-01） | **continuous PAD + dual-speed dynamics + emotion-memory coupling** | ⭐⭐⭐ **最有用** |
| **Can Generative Agents Predict Emotion?** | [2402.04232](https://arxiv.org/abs/2402.04232)（2024-02） | 新事件 vs 过去记忆的 **norm** 对比 | ⭐⭐⭐ **直接可用** |
| **EmotionPrompt** | [2307.11760](https://arxiv.org/abs/2307.11760)（2023-07） | 情绪刺激能提升 LLM 表现 | ⭐⭐ 反向用（我们能影响输出） |
| NegativePrompt | [2405.02814](https://arxiv.org/abs/2405.02814) | 负面情绪刺激也有效 | ⭐ |
| Generative Agents（Park 2023） | — | 没查到专门讲情绪的版本 | ⭐ |

### Sentipolis 的摘要原文（这段几乎在说我们）

> LLM agents are increasingly used for social simulation, yet **emotion is often treated as a transient cue, causing emotional amnesia and weak long-horizon continuity**. We present Sentipolis, a framework for emotionally stateful agents that integrates **continuous Pleasure-Arousal-Dominance (PAD) representation**, **dual-speed emotion dynamics**, and **emotion–memory coupling**.

**"emotional amnesia"（情绪失忆）** —— 这正是我们现在的问题：`mood.yaml` 只有一条，2 小时就衰减没了。

**它的诚实结论**（很重要）：

> Gains are **model-dependent**: believability increases for **higher-capacity models but can drop for smaller ones**, and emotion-awareness can **mildly reduce adherence to social norms**.

**翻译**：模型能力强的收益大，**小的可能反而变差**；而且情绪会**削弱对规则的遵守**。

**我们用 deepseek-chat，不是最强的那一档**——这条约束得记住。

## 一、三处一：情绪需要对比基准

### 现状

`src/relation/evaluate.ts` 让模型**直接给标签**：

```
"mood": {"情绪": "担心|平静|高兴|失落|好奇|烦躁", "强度": 0.5, "原因": "一句话说为什么是这个心情"}
```

**没有参照物**，所以它只能给个笼统的"担心"或"平静"。

### 参考实现

**Regan et al. 2024** 的做法（摘要原文）：

> After perceiving each new input, the agent generates **a summary of past relevant memories, referred to as the norm**, and **compares the new experience to this norm**.

```
新事件 → 捞相关往事，生成"常态"(norm) → 新事件 vs norm → 情绪 → 存记忆
```

### 改法

`src/relation/evaluate.ts` 的 prompt 里，**加一段已有记忆**，并要求对比：

```diff
+ 【以前的事】
+ {{最近 2-3 条相关的 episode/fact}}
+
+ 判断心情时先看上面这些：
+ - 他说的事和以前**不一样**（尤其相反）→ 情绪才该强
+ - 他说的事和以前一样，或者是第三次说同一件事 → 情绪该弱
+ - 举不出"哪里不一样"→ 把强度调到 0.3 以下
```

**位置**：`evaluate.ts` 的 `system` 拼装处（现在只拼了 `relationBlock` 和 `loadMood()`）。

**成本**：小。多喂 2-3 条记忆（约 300 字），多一段指令。

### 三处一的风险

1. **可能让它过度解读**：把"他今天说累"和"他上周说累"对比，得出"他一直在硬撑"——**过度推论**。
   缓解：prompt 里限定"只对比事实层面，不要推论心理"。
2. **喂错记忆**：`recall()` 按当前 query 捞，可能捞到不相关的。
   缓解：只取 `similarity > 0.3` 的，最多 3 条。
3. **成本增加**：每次评估多 300-500 token。现在每天 60 条消息，一天多 2-3 万 token。

## 二、三处二：两维表示 + 双速衰减

### 现状

```yaml
情绪: 担心
强度: 1
时间: 2026-10-26T10:25:06.466Z
```

**只有一维（强度）**，而且**衰减太快**：

```ts
// src/persona/mood.ts
const intensity = Math.min(1, m.intensity * Math.exp(-0.35 * hours))
// 半衰期 = ln2 / 0.35 ≈ 2 小时
```

```
1 小时  0.70
3 小时  0.35
6 小时  0.12
10 小时 0.03 → 归零
```

**人被骂一句气一整天很常见**——2 小时说不过去。

### 参考实现

**Sentipolis** 的两个组件：

1. **continuous PAD representation** —— 不是离散标签，是 PAD 三个连续值：
   - **P**leasure（愉悦度）
   - **A**rousal（唤醒度）
   - **D**ominance（掌控感）

2. **dual-speed emotion dynamics** —— **快慢两档**：
   - 快：即时情绪（秒~分钟级）
   - 慢：心境/底色（小时~天级）

**Russell 1980 的环形模型**是 PAD 的前身（只用 P 和 A 两维，被引 12,616 次）。

### 改法

**最小改动版**（不引入 PAD 三维，先加一维）：

```diff
 情绪: 担心
-强度: 1
+强度: 0.6
+效价: -0.4     # ← 新增：-1 很难受 ~ +1 很好受（Russell 的 valence 轴）
 时间: ...
```

**然后衰减按效价分两档**：

```ts
// 负面情绪衰减慢一点（负面偏差，人的通性）
const lambda = m.效价 < -0.2 ? 0.06 : 0.12    // 11 小时 vs 6 小时
const intensity = m.强度 * Math.exp(-lambda * hours)
```

**更大的改动版**（照 Sentipolis 做双速）：

```yaml
# 快：这次聊完的即时情绪
即时:
  情绪: 担心
  强度: 0.6
  效价: -0.4
  时间: ...

# 慢：底色，几天不变
底色:
  效价: 0.1
  唤醒: 0.3
  更新: 2026-10-20
```

**我建议先做最小改动版**——加 `效价` 一个字段，衰减分两档。双速留到验证过再说。

### 三处二的风险

1. **`mood.yaml` 格式变了**：老的只有 `强度`，新的有 `效价`。**要能读老格式**（无语价时按 0 处理，衰减用原来的 0.35）。
2. **衰减慢下来后，"气一整天"可能不自然**：比如吵完架 12 小时后还很生气。
   缓解：`强度 < 0.15` 时直接归零（现在的阈值是 0.05）。
3. **效价是模型给的，可能不准**：它可能把"担心"判成负，把"平静"判成 0，把"好奇"判成正——**这个方向对，但边界模糊**。

## 三、三处三：情绪和记忆耦合

### 现状

**两条线完全分开**：
- 情绪存在 `mood.yaml`
- 记忆存在 `episodes/` / `facts.md`

**只在 prompt 里各占一段**，互不影响。

### 参考实现

**Sentipolis** 的 **emotion–memory coupling**（摘要原文只说"emotion–memory coupling"，没展开细节）。

**但可以从 Regan 2024 推出具体做法**：情绪用了"过去的记忆"做参照，**反过来记忆也该被情绪加权**。

**我们已经做了一部分**：

```ts
// src/memory/recall.ts 的 lambdaOfEpisode
if (e.emotion?.trim() && imp >= 3) return high   // 有情绪的 episode 衰减慢
```

**这正是 McGaugh 2004（情绪加强记忆巩固）的实现**。

**缺的是另一半**：**当前情绪影响召回什么**。

**现象**：心情差的时候，人更容易想起不开心的事（mood-congruent memory，这是心理学里验证过的效应）。

### 改法

`src/memory/recall.ts` 的 `scoreOf` 里，加一个**情绪一致性**项：

```ts
// 当前情绪的效价
const moodValence = loadMood()?.效价 ?? 0

// episode 的情绪（需要先存成数值，现在只有文字）
// 简化：如果 episode 有 emotion 字段，且当前 mood 强烈（|valence| > 0.4），
//       给同号的 episode 加分
if (Math.abs(moodValence) > 0.4 && e.emotion) {
  const samePolarity = /* e.emotion 是正面词？负面词？ */
  if (samePolarity === (moodValence > 0)) score += 0.8
}
```

**问题**：`e.emotion` 是**自由文本**（"困惑又有点被触动"），**没法判断正负**。

**要么**：
- (a) 给 episode 加 `效价: number` 字段（distill 时让模型给）
- (b) 维护一个小词表（正面词：高兴/开心/放松/认同…；负面词：担心/失落/烦躁/困惑…）
- (c) 不做这条

**我倾向 (b)**——词表简单、可解释、不用改数据格式。

**匹配不到就当 0**（不加分不减分）。

### 三处三的风险

1. **可能强化负面循环**：心情差 → 想起更多不开心的事 → 心情更差。
   **这在人身上是真的，但对 bot 可能是 bug 不是 feature。**
   缓解：**只在正面情绪时加分，负面不加**（不对称处理）。
2. **词表覆盖不全**："困惑又有点被触动"这种混合情绪，词表判不了。
3. **效果难验证**：怎么知道"想起的事更符合当前心情"了？

## 四、优先级

| # | 改动 | 依据 | 参考项目 | 成本 | 风险 | 优先级 |
|---|---|---|---|---|---|---|
| 1 | **对比基准** | Regan 2024 + Lazarus 1991 | ✅ 有 | 小 | 中 | **P0** |
| 2 | **加效价 + 衰减分两档** | Russell 1980 + Sentipolis | ✅ 有 | 小 | 中 | **P1** |
| 3 | **情绪-记忆耦合** | Sentipolis + mood-congruent memory | ⚠️ 概念有，实现没有 | 中 | **高** | **P2（先别做）** |

### 为什么 P0 是对比基准

**它是唯一能解释"为什么它情绪总是平的"的**。

现在它只能说"担心"——因为没有参照物。给了参照物，它才可能说出"你今天和上次不一样"这种话。

**而且改法最简单**：`evaluate.ts` 里多拼一段 prompt。

### 为什么 P1 加效价

**一维强度表达不了"好受/难受"的区别**。强度 0.6 的"担心"和强度 0.6 的"高兴"，渲染出来是一样的"情绪 0.6"。

加了效价，prompt 里能说"你现在偏难受（-0.4），强度中等"。

**成本极低**：一个字段 + 一个 if。

### 为什么 P2 先别做

1. **Sentipolis 说了**："emotion-awareness can **mildly reduce adherence to social norms**"——情绪参与越多，越可能"不守规矩"
2. **负面循环风险**：心情差 → 想起更多坏事 → 更差。**这对陪伴 bot 是灾难**
3. **`e.emotion` 是自由文本**，判正负要么加字段要么维护词表，都不干净
4. **无法验证效果**

**等 P0/P1 跑一段时间、能观察到变化了再说。**

## 五、总风险表

| 风险 | 影响 | 缓解 |
|---|---|---|
| 对比过度解读 | 变成"心理分析"，反而更人机 | prompt 限定"只对比事实，不推论心理" |
| 喂错记忆 | 对比对象不相关，得出怪结论 | 只取 similarity > 0.3、最多 3 条 |
| 成本上涨 | 每天多 2-3 万 token | 可接受（现在一天 60 条消息） |
| `mood.yaml` 格式变 | 老数据读不了 | **必须兼容**：没有 `效价` 时按 0、衰减用原 0.35 |
| 衰减变慢 | 生气一整天不自然 | `强度 < 0.15` 归零 |
| 效价判不准 | 边界模糊 | 只取 -1/0/+1 三档，不搞精细 |
| **情绪削弱规则** | Sentipolis 实测有此现象 | P2 不做就是为了避开 |
| **负面循环** | 陪伴 bot 的灾难 | 不对称：只在正面时加权 |

## 六、诚实说明

**查证的**：
- 3 个参考项目的 arXiv 号 + 完整摘要（arXiv API 拿的）
- 18 篇文献的 DOI + 元数据（Crossref 查的，见 [情绪与心理研究.md](情绪与心理研究.md)）

**我的推断**：
- 三处改动的具体改法
- "最小改动版"（先只加效价，不做 PAD 三维）
- 衰减参数（0.06 / 0.12）
- 优先级排序
- **P2 先别做**这个判断（依据是 Sentipolis 的"削弱规则"和负面循环风险）

**没查到的**：
- Sentipolis 的**具体实现**（摘要没说 PAD 怎么算、双速怎么分离）
- **mood-congruent memory 的原始文献**（这是心理学里的老结论，但我这轮没查它，所以没列 DOI）
- **PAD 模型的原文献**（Mehrabian & Russell，可能有，我没查）

**如果要做 P2**，得先查 mood-congruent memory 的文献，确认它的效应量和边界条件。
