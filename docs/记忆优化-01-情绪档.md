# 情绪强度调衰减

## 问题（实测数据，不是推测）

跑了现有 9 条 episode：

```
有 emotion 的:      9 / 9   (100%)
importance >= 8 的: 0 / 9   (0%)
importance 分布:    {2: 2, 3: 7}
```

看 `src/memory/recall.ts:34` 的 lambdaOf：

```ts
const high = finiteOr(decay?.['高情绪'], 0.005)    // 139 天半衰期
const normal = finiteOr(decay?.['普通'], 0.02)     // 35 天
const imp = ...
if (imp >= 8) return high     // ← 0 / 9，从未触发
if (imp >= 5) return normal   // ← 0 / 9，从未触发
return normal * 2             // ← 9 / 9，全部走这里（17 天）
```

**结论：高情绪档是死代码。所有 episode 都用 17 天半衰期。**

连「凌晨两点他失眠说想看我成长」（importance=3，emotion=困惑又有点被触动）也是 17 天。

## 依据

McGaugh (2004, Annual Review of Neuroscience)：杏仁核在情绪唤起时加强海马对这段经历的巩固，**剂量相关**（越激动越牢）。

文献说的是**情绪**，不是**主观评分**。

## 改法

```ts
// src/memory/recall.ts
function lambdaOfEpisode(e: Episode, decay?: Record<string, number>): number {
  const high = decay?.['高情绪'] ?? 0.005
  const normal = decay?.['普通'] ?? 0.02
  const imp = Number.isFinite(e.importance) ? e.importance : 5

  // 有情绪记录 + 有一定重要性 → 高情绪档
  // 理由：emotion 有值说明当时确实有情绪波动（McGaugh 说的"唤起"）
  if (e.emotion?.trim() && imp >= 3) return high

  // 没有情绪记录但重要性很高 → 也进高档
  if (imp >= 8) return high

  return imp >= 5 ? normal : normal * 2
}
```

**门槛定 imp >= 3**：现有数据里 7 条 importance=3、2 条 =2。定 3 的话 7 条进高档，2 条留在低档——**区分度刚好**。

**注意**：`lambdaOf` 还有别的地方用（facts 的打分），所以**不动原函数**，新加一个 `lambdaOfEpisode`。

## 影响

- 7 条 episode 的半衰期：**17 天 → 139 天**
- 三个月后还剩：**0.03 → 0.64**
- prompt 里会多注入一些老 episode（因为分数变高了）

## 风险

1. **prompt 变长**：老 episode 分数变高，可能挤掉新 episode。
   缓解：召回还是按 score 排序，新的事 recency 仍然是 1.0，不会输。
2. **emotion 被滥用**：如果模型给每条都写情绪，等于全部进高档。
   缓解：看现有数据，emotion 的内容是真的情绪（"茫然，有点被推着走"），不是敷衍。
3. **改错函数**：`lambdaOf` 被 facts 也用。所以要新加函数，不改老的。

## 优先级

**最高**。这是修 bug，不是优化——高情绪档现在完全不工作。
