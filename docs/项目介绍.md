# Vesper（小暮）

> 一个跑在你自己电脑上、接进 QQ 的**长期陪伴型对话体**。
> 它记得你、会因为你改变、会在没人找它时自己想事情；它有自己的界面和插件生态。

---

## 一、它和"聊天机器人"差在哪

| | 常见 QQ 机器人 | Vesper |
|---|---|---|
| 回复来源 | 关键词 / 模板 / 单轮 LLM | 单轮 LLM + 分层记忆 + 关系状态 + 情绪 |
| 人格 | 写在配置里，固定 | **`persona/self.md` 它自己写**，会随反思漂移 |
| 你在界面上调的是什么 | 配置项 | **它这个人**（角色卡、情绪、经历、想法） |
| 扩展方式 | 装插件、改配置 | **插件可以给它加工具、加页面、加接入平台** |
| 主动性 | 只能被动回复 | 会主动插话、早晚问候、自己刷视频 |

一句话：**它不是工具，是一个有界面的"人"**。

## 二、自我页：它作为"人"的那一面

打开控制台的「自我」，看到的不是一个设置表单，而是**它的自我认知**。六个 tab 对应六个问题：

| tab | 回答什么问题 | 里面是什么 |
|---|---|---|
| **角色卡** | "我是谁" | 本名、日常称呼、外貌、基础身份、性格、语言风格、小动作、喜好、8 种情境下的反应 |
| **状态** | "我现在怎么样" | 关系值（四维 + 阶段）、当前情绪、最近的锚点 |
| **学习** | "我学会了什么" | 说话的技巧、这个群的黑话、被纠正过的判断 |
| **经历** | "我记得发生过什么" | 提炼过的情节（不是原始聊天记录） |
| **想法** | "我在想什么" | 它自己写下的近期思考 |
| **对话规则** | "我该怎么说话" | 回复延迟、分句方式、引用频率、口头禅统计 |

### 2.1 两个名字

自我页里是**两个**字段，不是「名字」一个：

```
本名        [小暮            ]    ← 角色卡里的，你定的，它不能改
日常称呼    [小暮            ]    ← 它自居的叫法，它自己取或你填
```

本名是身份，日常称呼是它平时说"我是 XX"用的那个。改名字这类事走**申请机制**（见 2.3）——它想改，得你批。

### 2.2 它能改自己的角色卡，但要过你

角色卡是**你定的底子**。但反思跑起来之后，它会挑自己真想改的字段（比如"核心特质"从"嘴硬"改成"更愿意先听完再开口"），打 1-10 分：

- 每 12 小时**最多真改 2 项**
- 改之前给你看理由，剩下的转成「想做的事」留到下次
- **总开关在设置里**：`它能自改角色卡` 默认**关**

关着的时候，它只能提申请；开着，它在限额内自己动。

### 2.3 三段式的所有权

`self.md` 的 frontmatter 有一个字段：

```yaml
所有权: 我写   # 或 它写
```

| 值 | 含义 |
|---|---|
| **我写** | 你写的「我是谁」**原文锁死**，它只能往「## 它补充的」那节追加，不能改写 |
| **它写** | 反思可以整体重写这段自述 |

配套的还有：

- **漂移检测**：每次改都算和上一版的相似度，低于 0.45 记一条 `drift.jsonl`（"它变了一个人"的痕迹）
- **历史快照**：每次写入前留一份，最多 60 版，能对比、能回滚
- **申请机制**：想改被锁的东西（名字、生日、外貌、身份）只能提申请，控制台「自我」页顶部会显示待批的申请

**设计取舍**：给它自己的意愿，但不给它最终决定权。

## 三、插件生态

插件不是"给它加个功能"，而是**给它加一种存在方式**。

### 3.1 四种类型

```json
{ "type": "tool" }       // 加一个它能调用的工具
{ "type": "panel" }      // 加一个自带前端页面的面板
{ "type": "transport" }  // 接入一个新平台（QQ 走 NapCat 就是这么接的）
{ "type": "event" }      // 只订阅事件，不加界面也不加工具
```

**`transport`** 是关键：QQ 接入本身就是一个插件（`demo-transport` 是可直接抄的骨架）。想接 Telegram / 微信 / 自建协议，写一个 transport 就行，不用改核心代码。

### 3.2 一个插件长什么样

最少两个文件：

```
plugins/hello/
  plugin.json
  index.js
```

```json
{
  "id": "hello",
  "name": "打个招呼",
  "version": "1.0.0",
  "type": "tool",
  "permissions": [],
  "entry": "index.js"
}
```

```js
export function activate(ctx) {
  ctx.registerTool({
    name: 'say_hello',
    description: '跟用户打个招呼',
    parameters: { type: 'object', properties: {} },
    run: async () => `你好，我是 ${ctx.id}`,
  })
}
```

**放进 `plugins/` 目录，刷新控制台就装好了。** 没有构建步骤、没有依赖安装。

### 3.3 ctx：能力按权限给

插件能拿到的 `ctx` 是**受控的**——没声明权限，对应的方法就是 `undefined`：

```js
ctx.id            // 插件 id
ctx.dataDir       // 这个插件独占的数据目录
ctx.config        // 用户在设置页填的配置
ctx.log(msg)      // 进日志页
ctx.on / ctx.emit // 自己插件内的事件总线
ctx.registerTool()// 任何类型都能调

// 下面三个要权限
ctx.fetch(url)         // permissions: ["net"]
ctx.readPersona(path)  // permissions: ["memory"]，只能读 persona/ 内
ctx.send(target, text) // permissions: ["message"]
```

所以插件里的写法是**防御式**的：

```js
if (typeof ctx.fetch !== 'function') {
  ctx.log('没声明 net 权限，跳过联网')
  return
}
```

### 3.4 权限模型：五项，默认全拒

| 权限 | 能干什么 | 边界 |
|---|---|---|
| `net` | 访问外部网络 | — |
| `memory` | 读记忆、档案、聊天记录 | 只能读 `persona/` 内 |
| `message` | 主动给你或群里发消息 | — |
| `files` | 读写项目目录 | **不能出项目根**，越界直接拒 |
| `shell` | 执行命令 | 只跑**白名单**命令（echo/date/git/node/python…），10 秒超时，**不经过 shell** |

`plugin.json` 里写什么就只给什么，**不写就一个都没有**。安装第三方插件时，控制台会在页面上把申请的权限列出来让你看见。

### 3.5 仓库里已有的示例

| 插件 | 演示什么 |
|---|---|
| `demo` | 最小的工具插件（3 行就能跑） |
| `demo-panel` | **自带前端页面**：插件自己渲染一个 HTML，能读自己的配置 |
| `demo-transport` | **接入一个新平台**的骨架（QQ 就是这么接的） |
| `weather` | 真实场景：`net` 权限 + `configSchema` + 失败降级 |

这五个加起来不到 500 行，是**可直接改的模板**，不是玩具。

## 四、其他能力（简单带过）

- **记忆**：分 `facts`（关于人的事实）和 `episodes`（发生过的事），按 tier 衰减（重要 139 天半衰期 / 平常 35 天），"被想起来"也会影响可及性。**宁可少给，不给错。**
- **情绪**：情绪 + 强度 + 效价 + 原因，会自然衰减，也会被事件触发。
- **关系**：信任 / 亲密 / 好奇 / 依赖四维 + 阶段（陌生→眼熟→朋友→亲近→亲密）+ 锚点（"分享私事""道歉"这类会被记住）
- **主动消息**：由头驱动（没做完的事、最近一起经历、早晚问候），不是定时任务；有静默时段和额度上限。
- **引用判定**：只在"多人/异步造成指代困难"时引用，@ 和私聊反而给负分。

这些都在 `docs/` 里有独立设计文档，此处不展开。

## 五、架构一句话

```
QQ ←WS→ NapCat ←→ 通道层（onebot）
                      ↓
              一条消息进来：
              去重 → 建人 → 聚合 → 打分/退避 → 生成 → 限流 → 分句发送 → 评估
                      ↓
        ┌─────────────┼─────────────┐
     记忆召回        关系/情绪      自我认知
        └─────────────┼─────────────┘
                      ↓
                 prompt 组装
```

- **技术栈**：TypeScript + Node 24（原生 type-stripping，**直接跑 `.ts`，不编译**）
- **运行时依赖**：只有 `ws` 和 `yaml` 两个
- **数据全在本地**：`persona/`（人格和记忆）、`data/`（日志和缓存）、`.env`（你的 Key）
- **打包**：Electron，内置 Node，绿色版解压即用

## 六、怎么跑

**普通用户**：去 [Releases](https://github.com/Wynn-Zheng/Vesper/releases) 下 `Vesper-x.x.x-win-x64.zip`，解压、双击 `Vesper.exe`。首次启动会自动生成配置并打开控制台。

**开发者**：

```bash
npm install
cp .env.example .env      # 填 DEEPSEEK_API_KEY / OWNER_QQ / CONSOLE_TOKEN
npm start
```

需要两样外部东西：**DeepSeek API Key**（填在设置页）和 **NapCat**（控制台引导安装）。
