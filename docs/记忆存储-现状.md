## 二、五种记忆，各有各的存法

### 1. 核心记忆 `core.md` —— **不衰减，只能人改**

```markdown
# 我一定不能忘的

> 这个文件只有我能改。它只读。
> 它可以提申请（在 core-requests.md），批准了才写进这里。
> 分四类：身份 / 边界 / 诺言 / 偏好。

## 边界

- 他讨厌被追问感受｜2026-10-26
```

| 项 | 值 |
|---|---|
| 谁写 | **只能你**（改文件或控制台）。它只能在 `core-requests.md` 提申请 |
| 上限 | 30 条 |
| 衰减 | **无** |
| 进 prompt | 最前面，优先级最高 |

**为什么不让它自己写**：现在给它打 importance 分都区分不出来（24 条经验全给 8 分），让它自己判断"什么该永远记住"必然膨胀。

### 2. 事实 `facts.md` —— **分两档，衰减不同**

```markdown
# 关于这个人的事实

## 平常

- 他四级基本没复习，对英语没兴趣，但坚持要考（2026-10-25，置信 0.95，公开）
- 他什么歌都听（2026-10-25，置信 0.9，私密）
- 他给我加了反思、记忆、总结几个功能（2026-10-25，置信 0.9，公开）｜我测试没啥问题
```

**格式**：`- 正文（日期，置信 0.9，可见性）｜他的原话`

| 档位 | 衰减 lambda | 半衰期 | 什么时候用 |
|---|---|---|---|
| `## 重要` | **0.005** | **约 139 天** | 约定、承诺、长期目标、明确的边界 |
| `## 平常` | **0.023** | **约 30 天** | 其他一切 |

**现在 7 条全是「平常」**（老数据没有 tier，一律按 normal 处理）。

**置信度衰减公式**：

```ts
base * Math.exp(-decay * days)     // decay 由档位决定
```

**被提及时会刷新**：`touchFact()` 更新 `lastConfirmed`，置信度从新的日期重新算。

### 3. 情节 `episodes/*.md` —— **看情绪决定忘多快**

```markdown
---
date: 2026-10-25
scope: private:1234567890
importance: 2
emotion: 有点无奈，但不想让他难堪
lastRecalled: 1793003371718
title: 他说加了刷视频的能力，可我这边接不上
---

他问我能不能刷视频，说给我加了这个能力。我这边跑不了...
```

**新写的还会有**：

```yaml
related: [2026-10-25-01, 2026-10-24-02]    # 相关情节的 id
recallCount: 3                              # 被想起过几次
```

**衰减**（幂律，不是指数）：

```ts
Math.pow(1 + days, -lambda * 8)
```

| 条件 | lambda | 半衰期 | 90 天后 |
|---|---|---|---|
| **有 emotion 且 importance ≥ 3** | 0.005 | **139 天** | 0.64 |
| importance ≥ 8（没有 emotion） | 0.005 | 139 天 | 0.64 |
| importance 5-7 | 0.02 | 35 天 | 0.24 |
| 其他 | 0.04 | 17 天 | 0.11 |

**而且被想起会变慢**：

```ts
const slowdown = 1 / (1 + Math.log(1 + recallCount) * 0.5)
```

**回忆 5 次的，一年后还剩 0.608；没回忆过的只剩 0.389。**

### 4. 原始对话 `raw/*.jsonl` —— **7 天**

```json
{"ts":1793003371718,"scope":"private:1234567890","role":"user","text":"在吗","senderId":"1234567890"}
```

| 项 | 值 |
|---|---|
| 谁写 | `boot.ts` 每条消息（过滤之后、聚合之前） |
| 保留 | 7 天（`recentRaw(7)`），文件不删 |
| 用途 | distill 的原料；`recall` 取最近 8 条给模型看上下文 |

### 5. 临时记忆 `temp/*.md` —— **7 天自动删**

```markdown
---
at: 1793006824522
query: 什么是 SSR
source: brave
ttlDays: 7
---

## 结果

1. 【标题】https://...

## 抓的正文
...
```

| 项 | 值 |
|---|---|
| 谁写 | 搜索功能（还没做） |
| 保留 | **7 天**，启动时清一次 |
| 上限 | 100 条 |
| **不进 distill** | 不会污染 `facts.md` |

**为什么单独一层**：搜索结果是**别人的话**，不是"关于这个人的事实"。

## 三、可见性：谁能看见什么

```ts
// src/memory/recall.ts
export function visible(scope: Scope, current: Scope): boolean {
  if (current.startsWith('private:')) return scope === current || scope === 'shared'
  return scope === 'shared' || scope === current
}
```

| 条目 scope | 私聊 A | 私聊 B | 群 1 | 群 2 |
|---|---|---|---|---|
| `private:A` | ✅ | ❌ | ❌ | ❌ |
| `group:1` | ❌ | ❌ | ✅ | ❌ |
| `shared` | ✅ | ✅ | ✅ | ✅ |

**群聊里还多一层**：facts 只注入 `visibility === 'public'` 的（私事在公共场合没有出现的理由）。

## 四、召回：怎么决定给模型看什么

### 打分公式

```
score = 新近 × 0.5 + 相关 × 3.0 + 重要 × 2.0
```

| 项 | 算法 | 权重 |
|---|---|---|
| 新近 | `Math.pow(1 + days, -lambda * 8)` | 0.5 |
| 相关 | 中文 bigram Jaccard 相似度 | **3.0**（最高） |
| 重要 | `importance / 10` | 2.0 |

**relevance 权重最高** —— "说得像"比"重要"优先。

### 数量

| 类型 | 取几条 |
|---|---|
| facts | 8 条（`eff ≥ 0.2`）+ 最多 2 条"很久没提但话题相关"的（faint） |
| episodes | 8 条（从 `limit` 来） |
| insights | 3 条 |
| open | 全部 |
| recent 原话 | **8 条** |
| 顺着 related 带出 | 最多 2 条 |

### 注入 prompt 的样子

```
【我一定不能弄错的】          ← core.md
边界：
- 他讨厌被追问感受

【关于他，我记得】            ← facts.md
- 他四级基本没复习，对英语没兴趣，但坚持要考
- 他什么歌都听（私事，对着别人别说）
- 他养过一只猫叫豆豆（很久没提了，我可能记得不全）   ← faint

【我想起来的事】              ← episodes
- 2026-10-25｜凌晨两点他失眠说想看我成长（当时：困惑又有点被触动）
  快两点了他还没睡...

【我对他的一些看法】          ← insights
- 他嘴上说不学，行动上不落

【还没问完 / 答应过的事】      ← open.md
- 他平时爱听什么歌，我还没得到回答

【最近说过的话】              ← raw
群代肝：现在就开始练
(ฅ]ω[*ฅ)：不要
群代肝：@小助手 你说对吧

【你说话的习惯】              ← 统计它自己说过的话
- 你平时一句话 17 个字左右
- 你最近 24% 的话里带问句，太多了

【你变过的地方】              ← self-history/drift.jsonl
- 1 天前你是这么说的：「...」
```

## 五、写入：谁在什么时候写

| 触发 | 写什么 | 频率 | 代码 |
|---|---|---|---|
| **每条消息** | `raw` | 实时 | `boot.ts` → `appendRaw` |
| **distill** | episodes / facts / insights / open / life | 攒够 20 条或隔 24 小时 | `scheduler/distiller.ts` |
| **反思** | `self.md`（自述/特征），`life.md` | 每 12 小时 | `self/reflect.ts` |
| **关系评估** | `relation.yaml`，`mood.yaml` | 每条回复后（异步） | `relation/evaluate.ts` |
| **刷视频** | `life.md`，`outward/watched.json` | 每天 1-2 次 | `outward/watch.ts` |
| **群名单** | `groups/*/members.json` | 1 小时 TTL + 每天全刷 | `people/groupcache.ts` |
| **快照** | `data/versions/*` | 每天一张 | `src/persona/version.ts` |

### distill 现在会先筛一遍

```ts
// 只把"值得提炼"的喂给模型（Kumaran 2016：重播是有选择的）
const picked = pickForDistill(list, existingEps)
```

**筛选规则**（`memory/filter.ts`）：

```
- 纯语气词（嗯/好的/哈哈哈哈）  -5
- 短于 4 字                    -3
- 约定/边界词（答应/不许/讨厌）  +3
- 和已有记忆不相似              最多 +2
```

**实际效果**：11 条 → 4 条，废话一条不留。

## 六、容量上限

| 文件 | 上限 | 超了怎么办 |
|---|---|---|
| `core.md` | 30 条 | 拒绝写入，逼你删一条 |

| `plays.md` | 高分 60 / 低分 20 | 丢最低分的 |
| `mood.yaml` | 最近 5 条序列 | 丢最旧的 |
| `raw/` | 不删（只读 7 天） | —— |
| `temp/` | 100 条 | 丢最旧的 |
| `groups/` | 30 个群 | —— |
| `session` | 40 轮 + 滚动摘要 | 压缩 |

## 七、几种容错

| 情况 | 处理 |
|---|---|
| `facts.md` 某行坏了 | 跳过那一行，不整份作废 |
| `mood.yaml` 缺「情绪」字段 | 返回 null（当没心情） |
| `members.json` 坏了 | 当空名单，下次刷新覆盖 |
| `raw` 某行是半个 JSON | 跳过 |
| `core.md` 没有 `##` 标题 | 整份当「身份」 |
| **`facts.md` 解析出的条数 < 原文 `- ` 行数** | **拒绝重写**（怕丢数据） |
| **群成员只拉回 1 个人** | **保留旧名单**（大概率是拉错了） |

## 八、和"人的记忆"的对应

| 人脑 | 我们 |
|---|---|
| 核心人格 / 底线 | `core.md`（不衰减） |
| 语义记忆（事实） | `facts.md`（按档位衰减） |
| 情景记忆（某件事） | `episodes/`（按情绪衰减） |
| 工作记忆 | `session`（40 轮 + 摘要） |
| 感觉记忆 | `raw`（7 天） |
| 道听途说 | `temp/`（7 天，不进长期） |
| 遗忘曲线 | **幂律**（Wixted 1991），不是指数 |
| 复习加强记忆 | `recallCount` 让衰减变慢（Roediger 2006） |
| 情绪加强巩固 | 有 `emotion` 的 episode 衰减慢（McGaugh 2004） |
| 遗忘是取不出来 | faint（提到还能捞出来，Bjork） |

**依据都在 [人脑记忆研究.md](人脑记忆研究.md) 里，每篇都有 DOI。**
