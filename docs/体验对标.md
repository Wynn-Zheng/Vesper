# 体验对标：性格 / 情绪 / 记忆 / 回答

> 调研日期：2026-10-26
> 目标：找出「已运行、持续更新、有人推荐」的项目在**体验**上的做法，对比我们的，把差距补上，同时不破坏我们自己的特点。

---

## 一、对标对象

| 项目 | 定位 | 为什么选它 |
|---|---|---|
| [ZifaMem](https://export.arxiv.org/abs/2607.17564) | 学术论文 + 开源 SDK，专为 AI 伴侣设计的结构化记忆 | **唯一给出实测数据**的：结构化记忆比塞原始历史，情感智能 +11.4%；多轮情感上下文 +39%；**情绪状态机无提升** |
| [plast-mem](https://github.com/moeru-ai/plast-mem) | 认知科学启发的记忆层，designed for Cyber Waifu | 和我们是同一类目标（虚拟伴侣），且有明确的架构文档 |
| [DebataBot](https://github.com/CN-BI5UNF/DebataBot) | Persona chatbot 框架，支持 QQ/NapCat + WebUI + 多 provider | **同渠道**（QQ/NapCat），可以直接对比部署形态 |
| [CyberWaifu](https://atomgit.com/gh_mirrors/cy/CyberWaifu/tree/main) | LLM + TTS 聊天机器人，长时记忆 + 现实感知 + QQ 部署 | 同渠道，且强调"长时记忆"和"现实感知" |
| [七牛云：从 Prompt 到人格](https://news.qiniu.com/archives/1765421879638) | 工程实践文，讲 AI 角色的 Prompt 与亲密度设计 | 总结了国内产品（猫箱/Talkie/EVE）的通行做法 |

## 二、四个维度逐项对比

### 2.1 性格（Persona）

| 做法 | 他们 | 我们 | 判断 |
|---|---|---|---|
| 人设载体 | System Prompt 里一段固定人设 | `persona/self.md`（自己写的自述 + 能力 + 在想什么），每轮渲染进 prompt | **我们更强**：人设是"它自己写的"，会随反思变化 |
| 自我认知更新 | 多数是静态配置 | `startSelfReflect()` 定时反思，写出新的自述；变化过大记进 `self-history/` | **我们更强** |
| 名字 | 预设 | 它自己取（`self.name` + `nameReason`） | **我们更强** |
| 说话风格 | 真人风格：短句、少表情、少旁白 | `说话.每轮最多条数=3`、`每条最多字数=40`，prompt 里明确"不要旁白" | **持平** |
| 边界 | 少见 | `人格.边界[]`（不假装、不承诺做不到的事），有专门一段"你做不到" | **我们更强** |

**结论**：性格这块我们是**领先**的，不动。

---

### 2.2 情绪（Emotion）

| 做法 | 他们 | 我们 | 判断 |
|---|---|---|---|
| 情绪状态 | 单轮快照（当前情绪 + 强度） | `persona/mood.yaml`：当前情绪 + 强度 + **最近 5 条序列** | **我们更强** |
| 情绪衰减 | 少见 | `decayedMood()` 指数衰减（半衰期约 2 小时），衰减到 0.05 以下返回 null | **我们有，他们多数没有** |
| 多轮情感上下文 | **ZifaMem 实测：比单轮快照 +39% 偏好** | 有，但**只给情绪名序列**（`开心 → 平静 → 低落`），**没给强度** | ⚠️ **差距在这** |
| 情绪状态机 | ZifaMem 实测：**额外加情绪状态机，5 个指标都没提升** | 我们的衰减算轻量状态机 | **保持现状，不加复杂状态机** |
| 情绪来源 | 少见 | `evaluateTurn()` 让模型输出 `mood: {情绪, 强度}`，写进 mood | **我们有** |

**结论**：唯一该改的是**情绪序列带上强度和趋势**。论文明确说多轮情感上下文有用，而我们给的信息量不够。

---

### 2.3 记忆（Memory）

| 做法 | 他们 | 我们 | 判断 |
|---|---|---|---|
| 结构 | ZifaMem：session summaries + episodic memories + consolidated user model | facts（事实）/ episodes（情节）/ raw（原始）/ shared（共享）/ insights | **我们更细**（5 层 vs 3 层） |
| 检索 | ZifaMem/Mem0 用向量；论文说「**filtered verbatim retrieval** 和它们统计等价」 | 字符 bigram 相似度 + 递推×相关×重要 | **我们的方向被论文支持**（复杂向量不是必须） |
| 遗忘 | 多数没有 | `lambdaOf(importance)`：重要性越高衰减越慢；`effectiveConfidence` 按确认日期衰减 | **我们更强** |
| 去重 | 向量相似度 | 字符相似度 0.7 阈值 + 黑名单兜底 | **我们弱一点**（抓不住同义改写） |
| 可见性 | 少见 | `visible(scope, current)`：private / group / shared 三层 | **我们更强** |
| 压缩 | ZifaMem 用 session summary | `compress.ts` 滚动摘要，超 20 条压成 ≤400 字 | **持平** |

**结论**：记忆结构我们领先。**唯一明显弱的是去重**——字符相似度抓不住"同一个意思换个说法"（之前实测过：同一事实改写 0.452，"喜欢猫"vs"喜欢狗" 0.500）。

**但**：论文说复杂检索不比简单的好。所以**不要上向量**，而是**在去重上加一层语义兜底**。

---

### 2.4 回答（Reply）

| 做法 | 他们 | 我们 | 判断 |
|---|---|---|---|
| 分句 | 多数整段发 | `splitBySentence()` 按字素切，每条 ≤40 字 | **我们更强** |
| 连续回复 | 少见 | 防抖聚合 + 连发多条（最多 3 条） | **我们更强** |
| 引用 | 少见 | `shouldQuote()` 按概率引用 | **我们有** |
| 表情包 | DebataBot 有 | 有（收集 + 按情绪挑） | **持平** |
| 不回 | 少见 | `occasionallySkip` + 退避 | **我们更强** |
| 自评 | 少见 | `judgeReply()` 打分 → 学进 plays | **我们更强** |

**结论**：回答这块我们全面领先。

## 三、该改什么（按证据强度排序）

### 🔴 P0：情绪序列带强度和原因

**证据**：ZifaMem 论文实测「多轮情感上下文 vs 单轮快照 +39% 偏好」。

**我们的现状**：
```
- 你现在的心情：开心（强度 0.8）
- 最近这几轮你的情绪变化：开心 → 平静 → 低落
```

**问题**：只有名字，模型看不出"是从很开心的 0.9 掉到 0.2"，也看不出"为什么掉"。

**改成**：
```
- 你现在的心情：低落（强度 0.2）
- 最近的情绪：开心 0.9（因为他说要请你吃饭）→ 平静 0.5 → 低落 0.2（因为他说来不了了）
```

**需要**：`MoodEntry` 加 `reason?: string`，`evaluateTurn` 里让模型给一句原因。

**成本**：低（改 2 个文件）。

---

### 🟡 P1：记忆去重加语义兜底

**证据**：我们自己实测的——字符相似度分辨不出同义改写。

**现状**：`distill` 和 `appendFacts` 用 `similarity > 0.7` 判重。

**问题**：
- 同一事实换个说法（sim 0.452）→ **重复入库**
- "喜欢猫" vs "喜欢狗"（sim 0.500）→ **被判成不同**（这个对）

**改法**（不上向量，避免过度设计）：
- 入库前让模型判断"这条和已有的某条是不是同一件事"
- 只在**候选相似度在 0.3-0.85 之间**时问模型（低的不可能重复，高的直接判重）—— 省 token

**成本**：中（改 distill + facts，加一次模型调用但只在灰色地带）。

---

### 🟢 P2：情绪原因写进 `self.md` 的"最近在想"

**证据**：七牛云文章提到"心理活动"能增强沉浸感。

**现状**：`self.thinking` 是反思时写的，和情绪无关。

**改法**：情绪变化大时（强度差 > 0.4），把原因也写进 `thinking`。

**成本**：低。

---

## 四、明确不改的（我们比他们好，或被证据否定）

| 项 | 原因 |
|---|---|
| **加复杂情绪状态机** | ZifaMem 实测无提升 |
| **上向量检索** | 论文说 filtered verbatim 和向量统计等价 |
| **改成人设静态配置** | 我们的自我反思比静态人设好 |
| **去掉隐私分层** | 多数项目没有，但这是我们做得对的地方 |
| **去掉"它自己的生活"** | 刷视频/life.md 是差异化特点 |
| **去掉不假装边界** | 防幻觉的关键 |
| **缩短关系阶段** | 6 档比通行的 3 档细 |

---

## 五、实施顺序

1. **P0 情绪序列带强度 + 原因**（改 `mood.ts` / `evaluate.ts` / `relation/format.ts`）
2. **P2 情绪原因写进 thinking**（改 `reflect.ts` 或 `evaluate.ts`）
3. **P1 记忆去重语义兜底**（改 `distill.ts` / `facts.ts`）
4. 每步都要能通过现有 36 项检查

---

## 六、保留的特点清单（改的时候必须保住）

- 自我反思（`startSelfReflect`）—— 人设是它自己写的
- 名字自己取
- 6 层关系阶段
- 隐层可见性（private / group / shared）
- 事实的 confidence 衰减 + 确认机制
- 黑名单（删掉的事实不会复活）
- 它自己的生活（刷视频 + life.md）
- 边界（不假装、不承诺做不到）
- 自诊断（找 bug 并说出来）
- 7 组 14 页的控制台
