# 遗忘：不删内容，只降可及性

## 问题

现在 `src/memory/recall.ts:175`：

```ts
const facts = allFacts
  .map(f => ({ f, eff: effectiveConfidence(f, now) }))
  .filter(x => x.eff >= 0.2)      // ← 低于 0.2 直接丢掉
  ...
```

而 `effectiveConfidence` 是 `base * Math.exp(-0.023 * days)`：

- 一年后：**0.0002**
- 等于**永久删除**

## 依据

Bjork & Bjork 的「新失用理论」区分：

| | 存储强度 | 提取强度 |
|---|---|---|
| 会下降吗 | **不会，只增不减** | **会** |
| 遗忘是什么 | —— | **取不出来**，不是痕迹消失 |

**所以"置信度衰减到 0.2 以下就过滤"是错的模型**——内容该留着，只是默认不注入。

## 改法

**不改存储**（facts.md 里的 confidence 保持记录时的值），**只改召回的过滤条件**：

```ts
// 旧：eff < 0.2 直接丢
// 新：eff < 0.2 时，如果和当前话题够像，仍然带出来（但不占正常名额）
const strong = allFacts.filter(f => eff(f) >= 0.2)
const faint = allFacts
  .filter(f => eff(f) < 0.2)
  .filter(f => similarity(f.text, query) > 0.5)    // 关键词精确命中
  .slice(0, 2)                                     // 最多 2 条

const facts = [...strong, ...faint]
```

**渲染时给 faint 加标注**：

```
【关于他，我记得】
- 他四级坚持要考              ← 正常
- 他养过一只猫叫豆豆（很久没提了）  ← faint
```

## 影响

- 一年没提的事，**提到关键词还能想起来**
- 平时不会占 prompt 空间（eff >= 0.2 的门槛不变）

## 风险

1. **带出无关老事**：similarity > 0.5 这个门槛是**我拍的**，没数据支撑。
   缓解：先只带 2 条，观察一段时间。
2. **标注可能让它说错话**：说"很久没提了"可能让对方觉得被冷落。
   缓解：标注只在 prompt 里，不要求它说出来。
3. **0.2 这个阈值本身没验证过**：现在没数据说 0.2 是合适的。

## 优先级

**中**。现在只有 7 条 fact，一年后的事还没发生。但改法简单（一个 filter），可以先做。
