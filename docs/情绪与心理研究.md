## 二、情绪理论有三派，我们只用了最粗的一派

### 派 1：基本情绪（Ekman 1992）

**主张**：有几种天生、跨文化共通的基本情绪。Ekman 最初提 6 种：

```
愤怒 厌恶 恐惧 快乐 悲伤 惊讶
```

**证据**：跨文化面孔表情识别实验（包括与世隔绝的 Fore 部落）。

**问题**：后来扩展到 7、15、甚至更多种，**边界不清**。而且"基本"这个前提被质疑——Barrett 就不同意。

### 派 2：维度模型（Russell 1980；Russell & Barrett 1999）

**主张**：情绪不是离散的盒子，是**二维连续空间**：

```
        高唤醒
          │
  紧张 ·  · 兴奋
          │
负面 ─────┼───── 正面
          │
  沮丧 ·  · 平静
          │
        低唤醒
```

两个轴：
- **valence（效价）**：好受 ↔ 难受
- **arousal（唤醒）**：激动 ↔ 平静

**"核心情感"（core affect）**就是这两个轴的当前值，**不需要命名**。

**被引 12,616 次**，是情绪研究里被引用最多的模型之一。

### 派 3：建构情绪（Barrett 2016/2017）

**主张**：情绪不是"被触发的固定程序"，是**大脑对内部感受（interoception）作出的预测和分类**。

> 你感到"心跳加快 + 手心出汗"，大脑根据当下情境把这一团感受**归类**成"紧张"还是"兴奋"。

**含义**：
- 同一个生理状态，在不同情境下是不同情绪
- **没有情境就没有情绪**
- 情绪是**建构**出来的，不是**读取**出来的

## 三、⭐⭐ 对我们最关键的一篇：情绪需要"对比基准"

### Can Generative Agents Predict Emotion?（2024）

**核心机制**（摘要原文）：

> introducing a novel architecture in which **new experiences are compared to past memories**. Through this comparison, the agent gains the ability to understand new experiences in context, which **according to the appraisal theory of emotion is vital in emotion creation**.
>
> After perceiving each new input, the agent generates **a summary of past relevant memories, referred to as the norm**, and **compares the new experience to this norm**. […] The **PANAS**, a test of affect, is administered to the agent, capturing the emotional state of the agent after the perception of the new event. Finally, **the new experience is then added to the agent's memory to be used in the creation of future norms**.

**流程**：

```
新事件
  ↓
从记忆里捞出相关往事，生成一个"常态"（norm）
  ↓
新事件 vs norm 对比 → 产生情绪
  ↓
用 PANAS 量表测量（正负情绪各 10 项）
  ↓
新事件存进记忆，成为未来的 norm 的一部分
```

**依据是 appraisal theory（Lazarus 1991）**：情绪来自"评价"，而评价需要**参照**。

**它的结论很诚实**：

> The **mixed results** suggests that introducing context can **occasionally** improve the emotional alignment of the agent, but **further study and comparison with human evaluators is necessary**.

**没有吹**——说"偶尔有改善，还需要进一步验证"。

## 四、⭐⭐ 我们现在的实现和这些文献的差距

> 本节 2026-11-08 重写过 —— 之前写的还是 `exp(-0.35h)` 时代的实现，早就对不上了。

### 现状（`persona/mood.yaml` + `src/persona/mood.ts`）

```yaml
情绪: 好奇
强度: 0.6
效价: 0.2          # -1 很难受 ~ +1 很好受，0 平淡
时间: 2026-11-04T09:50:01.031Z
最近:              # 最近几条，给"情绪有连续性"用
- { 情绪: 平静, 强度: 0.3, 时间: 2026-11-04T09:49:01.031Z }
```

```ts
// 按效价分两档衰减（不是 2 小时就没了）
const lambda = valence < -0.2 ? 0.06 : 0.12
const intensity = Math.min(1, m.intensity * Math.exp(-lambda * hours))
if (intensity < 0.1) return null
```

负面情绪约 11 小时衰到阈值、其余约 6 小时。依据是 Frijda (1988) 的习惯化
+ 负面偏差（坏情绪比好情绪持续更久）。

### 产生方式（`src/relation/evaluate.ts`）

不是让模型凭空说"我现在什么心情"，而是**给它几段以前的事当对比基准**：

```
（下面如果列了我记得的事，就对比着看）
...
**只对比事实层面，不要推论他的心理。**
```

这就是 Regan 2024 说的「情绪 = 新事件 vs 过去记忆的 norm 对比」。

## 五、三条改法，两条已经落地

> 2026-11-08 更新：A 和 B 都做完了，C 还没动。下面留着当初的分析，方便看"为什么这么改"。

### A. 情绪需要对比基准（Regan 2024 + Lazarus 1991）—— ✅ 已做

**当时的问题**：让它直接说"我现在是什么心情"，只能给个笼统的"担心"或"平静"。

**文献说的**：情绪来自**新事件 vs 过去常态**的对比。

**举例**：

| 场景 | 有对比 | 没有对比 |
|---|---|---|
| 他说"我四级过了"（以前说没复习） | **意外的好** → 高兴 0.9 | 平静 0.3 |
| 他说第三次"我四级过了" | **没有意外** → 高兴 0.2 | 平静 0.3 |

**实际做法**（`src/relation/evaluate.ts`）：捞最近相关的几段 episode，附在提示里，
并明确要求**只对比事实层面，不要推论他的心理**。

### B. 衰减太快（Frijda 1988）—— ✅ 已做

**当时**：`exp(-0.35 * hours)` → 半衰期 2 小时，10 小时就归零。

**Frijda 1988 的"情绪法则"**：情绪会习惯化，但**不是两小时就消失**。

**实际做法**（`src/persona/mood.ts`）：

| 效价 | 衰减系数 | 到阈值（0.1）大约 |
|---|---|---|
| `< -0.2`（难受） | `0.06` | 11 小时 |
| 其余 | `0.12` | 6 小时 |

依据是负面偏差：坏情绪比好情绪持续更久。

顺带把 `效价` 字段补上了（-1 ~ +1），`最近` 保留最近几条，情绪不再是孤零零一个值。

### C. 缺"情绪调节"（Gross 1998）—— ❌ 还没做

**文献说的**：人有 5 个调节时点——情境选择 / 情境修改 / 注意分配 / 认知重评 / 反应调节。

**现在**：情绪只靠衰减慢慢淡掉，**没有"它自己缓下来"的机制**
（代码里搜不到"情绪调节"）。

**最值得加的是"认知重评"**：同一件事换个角度，情绪就变了。
真要做得有个"重新想一想"的触发点，现在没有。
