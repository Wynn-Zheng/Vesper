## 一、30 秒了解

**Vesper（小暮）** 是一个跑在本地的 QQ 角色机器人：
接 NapCat（QQ 协议端）收消息，用 DeepSeek 生成回复，带分层记忆、关系、情绪，
能自己反思改人设，还有一个本地控制台。

- TypeScript + Node 24（原生 type stripping，**不编译也能跑**）
- 运行时依赖只有两个：`ws`、`yaml`
- 前端是单文件 `console/index.html`（**没有构建步骤**）
- 桌面版 = Electron 壳 + 内置 Node，用户机器不用装 Node

## 二、立刻能跑的四条命令

```bash
# 1. 单元测试（必须单进程，否则全局状态会串）
node --test --test-isolation=none --test-force-exit test/*.test.ts

# 2. 全量检查（需要后端在 7788 上跑，且 token 对得上）
node --env-file=.env src/index.ts      # 另开一个窗口
node scripts/check-all.ts

# 3. 打包（生成 release/ + dist-update/）
node scripts/package-electron.ts

# 4. 发布到更新服务器
node scripts/deploy-update.ts --no-build
```

⚠ **三个会浪费你半小时的坑**：

1. **7788 只能有一个服务**。源码跑（token 在 `.env`）和桌面版（token 在
   `%APPDATA%\vesper\data-root\.env`）**token 不一样**，同时开会让你以为
   "检查突然全红"。跑 `check-all` 前先关桌面版。
2. **桌面版必须用 `explorer.exe` 启动**：
   `explorer.exe "G:\bot\Vesper-0.1.6-win-x64\Vesper.exe"`。直接执行会立刻退出（不报错）。
3. **测试单进程跑**（`--test-isolation=none`），所以**全局状态会串**：
   写测试时群号、临时目录都要唯一，否则上一个用例的额度/旁听会漏进来。

## 五、必须知道的五个概念

| 概念 | 一句话 |
|---|---|
| **对话规则页** | 「自我 → 对话规则」由 `src/console/talk-schema.ts` 驱动，26 项；加一项只改这一个文件。写入走 `/api/talk-rules`，带类型/范围校验 + 写后 YAML 复验 |
| **三档参与** | 只听 / 熟人续话 / 自己判断，写 `rules.yaml` 的 `行为.群聊模式`，入口在「设置 → 权限」 |
| **旁听（heard）** | 群里没叫它的消息进 `Session.heard`（12 条 / 2 小时 / 按人限额），**不进 turns**，否则模型以为自己说过 |
| **合批归属** | 一批"算谁说的" = **第一条叫到它的那条**（`Buffer.primary`），不是最后一条 |
| **插件权限** | 4 项：net / memory / message / files，默认全拒；`shell` 已移除 |

## 七、发布流程（0.1.9 走过的完整路径）

```bash
# 1. 升版本：改 package.json 的 version（发布脚本会拒绝相同版本号）

# 2. 打包（生成 release/Vesper + dist-update/{app.tar.gz,latest.json}）
node scripts/package-electron.ts

# 3. 裁 locales（不裁 111MB，裁完 101MB）
Get-ChildItem release\Vesper\locales | ? { $_.Name -notin @('zh-CN.pak','en-US.pak','zh-TW.pak') } | rm

# 4. 打 zip（名字里的版本号要和 package.json 一致）
Compress-Archive -Path "release\Vesper\*" -DestinationPath "release\Vesper-0.1.9-win-x64.zip"

# 5. 上传（读 .env 的 DEPLOY_*，自动备份旧包为 app.prev.tar.gz）
node scripts/deploy-update.ts --no-build
```

**发布脚本做的事**：核对本地 sha256 → 查服务器当前版本（相同就拒绝）→
备份旧包 → scp 上传 → `chown www:www` → 带 token 拉回 `latest.json` 核对 →
下载 `app.tar.gz` 核对字节数。

**服务器信息不进仓库**：`web.wynnzheng.icu/QQbot`；主机/用户/路径在
`.env` 的 `DEPLOY_HOST / DEPLOY_USER / DEPLOY_PATH`，密钥 `~/.ssh/qqbot_deploy`。

## 十一、十句话记住这个项目

1. 单文件前端 + 无构建 —— 改完刷新就生效，别找 webpack。
2. `rules.yaml` 是行为总闸，但**别手改**，走控制台（有校验）。
3. 记忆按角色卡隔离，`people/` 跨卡共享。
4. 群里"算谁说的"取第一条叫到它的，不是最后一条。
5. 旁听不进 turns，否则模型以为自己参与过。
6. 发不出去的话要从历史里撤掉（`popLastAssistant`），否则它会重复说。
7. 插件 `files` 的根是自己的 dataDir；`shell` 权限已经没了。
8. 面板 iframe 是沙箱，通过 `postMessage` 桥调后端，**拿不到控制台 token**。
9. 任何落盘都用 `writeAtomic`，别直接 `writeFileSync`。
10. 改完跑 `check-all` —— 它会抓到你没注意的地方（这几轮抓出十几条）。
