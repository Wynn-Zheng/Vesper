# 视频脚本：Vesper（小暮）项目介绍

> 用于 B 站项目介绍视频。原则：每句话都能在仓库里找到对应实现，
> 不写"强大的 AI 框架"这类没有信息量的形容词。
> 演示素材按 Tap 排列，录之前先照着对应文档跑一遍。

---

## 一、开篇（约 40 秒）

大家好，我是妄言。

这期讲一个我从零写的项目：**Vesper，一个跑在本地的 QQ 角色机器人**。
它不叫"AI 助手"，因为我想要的是另一种东西——一个会记事、会误解、也会自己改人设的"人"。

先说清楚它不是什么：
不是给大模型套一层对话框，也不是一个"配置好回复模板"的自动应答机。

它做的是三件比较实的事：

**第一，记忆是分层的，而且会忘。**
事实、情节、洞察分开存，定期衰减，靠"能不能被想起来"决定要不要进上下文——
不是把所有聊天记录塞进 prompt 里。

**第二，人设是长出来的，不是我在配置里写死的。**
它会反思、会写自己的自述，甚至可以申请改自己的角色卡——但**必须过我这一关**。

**第三，控制台是本地的，数据也在本地。**
模型 API 之外，没有第二个服务器知道它在跟谁说话。

至于安装：打包好的版本，双击就能开，不用装 Node。
只有接 QQ 那一步要装 NapCat（QQ 协议端）——控制台里有一键安装，跟着点就行。

下面从安装到调参，把十个部分完整走一遍。

---

## 二、目录

### 【Tap 1】安装部署：从下载到第一次说话
- 讲：两种安装方式（免装 Node 的绿色版 / 源码跑）、目录结构、数据存在哪
- 演示：解压 → 双击 → 控制台自动打开 → 看到 `.env` 自动生成
- 钩子：*不用配环境变量，第一次启动它会自己写一份配置给你改*

### 【Tap 2】前置环境：模型 Key 与 QQ 接入
- 讲：DeepSeek API Key 填在哪、控制台 token 的作用、NapCat 是独立进程
- 演示：填 Key → 控制台「接入平台 → QQ → 一键安装 NapCat」→ 扫码登录
- 钩子：*NapCat 故意不打包进去——它要单独升级，绑在一起只会互相拖累*

### 【Tap 3】控制台与基础配置
- 讲：九个页面各自管什么（仪表盘/自我/插件/成员/日志/对话/操作/设置/更多）
- 演：页面逐个点一遍，重点看「设置」里改完**不用重启**（配置热重载）
- 钩子：*为什么控制台是单文件 HTML——改一行刷新就能看见，不用等构建*

### 【Tap 4】角色卡：让它成为"某个人"
- 讲：`persona/self.md` 的三段式所有权（哪些你能改、哪些它自己写、哪些要申请）
- 演：改一句人设 → 看回复风格怎么变 → 打开「自我 → 角色卡」看两个名字
- 钩子：*它能改自己的角色卡，但这道门开得很小：要申请，要你批*

### 【Tap 5】角色资源与归属：版本、名单、谁能用它
- 讲：人格快照（每 30 分钟检查改动，可回滚）、人物档案、群/成员白黑名单
- 演：改人设 → 看「版本」多出一条 → 回滚；再演示把一个人加进黑名单
- 钩子：*它改自己之前，系统会先留一份快照——改坏了能退回去*

### 【Tap 6】插件生态：四种类型，各自能干什么
- 讲：`tool`（给模型加工具）、`panel`（自带页面）、`event`（听事件）、`transport`（接新平台）
- 演：装一个示例插件 → 看它注册的工具出现在对话里 → 打开面板 → 热重载
- 钩子：*插件面板跑在沙箱 iframe 里，拿不到控制台 token——它是客人，不是管理员*

### 【Tap 7】能力开关：记忆抽取、主动消息、定时自检
- 讲：三个自动行为的开关和边界
  - 记忆抽取：每 30 分钟从原始对话里提事实、情节（不是全存）
  - 主动消息：看"由头"不看频率，静默时段不说话
  - 定时自检：每 6 小时扫一次日志，自己发现问题
- 演：看「自我 → 学习/经历」里的条目增长；调静默时段验证它真的闭嘴
- 钩子：*这三件事都不在你发消息的那条路上，所以不会拖慢回复*

### 【Tap 8】默认权限策略：为什么它默认"很保守"
- 讲：三层闸门
  1. 名单：群/成员白黑名单（默认拒绝）
  2. 参与方式：只听 / 熟人续话 / 自己判断（决定"要不要 @"）
  3. 插件权限：默认全拒，声明了才给
- 演：切「只听」验证它一个字都不说；把插件权限去掉看能力消失
- 钩子：*默认值的选择能看出一个项目的态度——这里全部选"不给"，要你手动开*

### 【Tap 9】扩展与自定义：改哪儿、怎么改
- 讲：加一个工具、写一个插件、改 prompt、改规则；哪些改动不用重启
- 演：加一个 `hello` 工具 → 对话里真的调到 → 再改一条规则看行为变化
- 钩子：*代码里所有"为什么这么写"都留在注释和文档里，包括被推翻的方案*

### 【Tap 10】启动与调参：让它像人，而不是像开关
- 讲：防抖档位、发言频率、退避、限流、上下文压缩阈值
- 演：同一句话在「安静/活跃」档下的不同反应；把频率调低看它变得多冷淡
- 钩子：*参数不是随便给的默认值——每一条都对应一个"人不会这样"的具体毛病*

## 四、录制前要核对的几件事（避免被评论区纠）

| 说法 | 实际 | 处理 |
|---|---|---|
| "安装即可启动对话交互" | Electron 版装完即用，但接 QQ 仍需装 NapCat | 开篇已改成"双击能开，接 QQ 要装 NapCat（有一键安装）" |
| "分层记忆管理" | 事实/情节/洞察/待问/核心，带衰减与召回 | 讲的时候说出"会忘、靠召回"这两点，别只说"分层" |
| "自动交互规则/触发频率" | 防抖档位、发言频率、退避、静默时段 | 用"防抖档位"这个真实名词 |
| "插件扩展、按需开放权限" | 四项权限：net / memory / message / files | 说清"默认全拒" |
| 包体积 | 约 232 MB，不含 NapCat | 提到时加"不含 NapCat" |
