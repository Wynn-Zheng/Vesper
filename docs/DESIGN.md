# QQbot 控制台设计规范

> 一句话：**近黑底、发丝线、单一低饱和强调色、间距只走 4 的倍数**。
> 参考血统：Linear 的克制 + Vercel 的中性 + Notion 的信息层级。
> 目的：去掉「AI 味」——渐变、发光、高饱和、大圆角、情绪化文案。

## 1. 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0a0b0d` | 页面底（近黑，带一点暖，不用纯黑） |
| `--panel` | `#121316` | 一级面板（卡片、侧栏） |
| `--panel2` | `#17181c` | 二级面板（内嵌块、输入框底） |
| `--line` | `rgba(255,255,255,.07)` | 发丝边框，所有分层都靠它，不靠阴影 |
| `--text` | `#f2f3f5` | 主文字 |
| `--dim` | `#9aa0a8` | 次要文字（标签、说明） |
| `--dim2` | `#6b7079` | 弱文字（单位、时间戳） |
| `--blue` | `#5e6ad2` | **唯一强调色**：选中态、关键数字、主按钮 |
| `--green` / `--red` / `--yellow` / `--purple` / `--pink` | `#5c9c74` `#c46a63` `#b3924a` `#8a86c4` `#b57a94` | 只用于状态与数据，不铺底、不描边 |

规则：

- 强调色占屏 **≤ 5%**，只出现在「当前激活」「关键数值」「主操作」三处
- 卡片与背景的明度差 ≤ 8%，**不做渐变、不做发光**
- 需要区分层级时：加一层发丝边框（`--line`）或换一档面板色，**不要加阴影和光晕**

## 2. 间距

只用 4 的倍数，写死这几档：

| 令牌 | 值 | 场景 |
|---|---|---|
| `--s1` | 4px | 图标与文字、标签内边 |
| `--s2` | 8px | 同一组内的元素 |
| `--s3` | 12px | 字段行之间 |
| `--s4` | 16px | 卡片之间、卡片内边距 |
| `--s5` | 24px | 区块之间 |
| `--s6` | 32px | 页面大分段 |
| `--s7` | 40px | 顶部/底部留白 |

规则：

- **禁止**出现 6 / 10 / 14 / 18 / 22px 这类"看起来差不多"的间距
- 同一行里两个元素的距离 ≤ 组间距（避免"该近的不近、该远的太近"）
- 卡片之间统一 `--s4`（16px），卡片内部 padding 统一 14/16

## 3. 字号

| 令牌 | 值 | 场景 |
|---|---|---|
| `--fs-xs` | 11px | 单位、时间、计数（`--dim2`） |
| `--fs-sm` | 12px | 标签、说明、表格头 |
| `--fs-md` | 13px | 正文、表单内容 |
| `--fs-lg` | 14px | 卡片标题、强调行 |
| `--fs-xl` | 20px | 列表里的关键数 |
| `--fs-2xl` | 28px | 仪表盘主数 |

规则：

- 行高：正文 1.55，标题 1.3
- 数字统一 `font-variant-numeric: tabular-nums`
- 不使用 10.5 / 11.5 / 12.5 这类半像素字号

## 4. 圆角与阴影

| 令牌 | 值 | 场景 |
|---|---|---|
| `--r-sm` | 6px | 按钮、输入框、标签 |
| `--r-md` | 10px | 卡片 |
| `--r-lg` | 12px | 大面板（hero、抽屉） |
| `--shadow` | `0 1px 2px rgba(0,0,0,.35)` | 仅用于浮层（抽屉、下拉） |

**圆角上限 12px。阴影只给浮层，卡片一律无阴影。**

## 5. 组件规则

- **卡片**：`--panel` 底 + 1px `--line` 边框 + `--r-md`，padding 14/16，标题 12px `--dim` 600
- **表格/列表**：行高 40px，行间用 1px `--line` 分隔，不用斑马纹
- **按钮**：默认透明底 + 边框；主操作 `--blue` 底 + 白字；危险操作 `--red` 文字
- **输入框**：`--panel2` 底 + `--line` 边框，focus 时边框变 `--blue`（不发光）
- **标签/状态**：小圆点 + 文字，不用彩色胶囊大面积铺色
- **图表**：单系列折线 1.5–2px，面积填充透明度 ≤ 10%，网格线极低对比度（`--line` 的一半）

## 6. 布局

- 侧栏 190px 固定，右侧内容区最大宽度不设死（自适应），左右 padding 20–24px
- 内容区卡片统一 16px 间距，同一屏内卡片**等高对齐**（grid `align-items: stretch`）
- 表单：label 72px 固定宽 + 输入框撑满，行间 10–12px
- 长内容必须给 `min-width: 0` + `overflow: auto`，**禁止撑破容器**

## 7. 文案

- 不用感叹号、火焰、星星等情绪符号
- 状态用中性描述：「+12% 较上周」而不是「暴涨 12% 🔥」
- 空状态给一句功能说明 + 一个操作入口，不留纯空白

## 8. 禁忌清单

- ❌ 线性渐变 / 径向光晕 / 彩色投影
- ❌ 圆角 > 12px、玻璃拟态、霓虹描边
- ❌ 同一屏出现两种以上饱和色
- ❌ emoji 当图标用（图标一律单色线性 SVG）
- ❌ 半像素字号、非 4 倍数间距
