## 四句话记住现在的方案

1. **自己写**，不装框架；借鉴 MaiBot 的分层、Generative Agents 的检索公式、qq-final 的手感。
2. **人格和记忆是纯文件**，行为规则全在 `persona/rules.yaml`，改文件不改代码。
3. **本地能力走 HTTP 服务**（A → B 演进），不跨语言混写；任何一个服务挂了都不影响聊天。
4. **先本机跑通，再上云**；NapCat 只用小号，且只监听 `127.0.0.1`。
